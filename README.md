# Arthur Pacheco | Advocacia Trabalhista & Previdenciária

Website institucional de alta performance desenvolvido com Next.js 16 (App Router), React 19, Tailwind CSS v4, GSAP 3 e Lenis Smooth Scroll.

## 🚀 Tecnologias

- **Framework**: Next.js 16.3.5 (Turbopack)
- **UI**: React 19 + Tailwind CSS v4
- **Animações**: GSAP 3.15 + ScrollTrigger + @gsap/react + Lenis 1.3.26
- **Deploy**: Cloudflare Pages / Vercel (Static HTML Export `out/`)
- **Conformidade**: Provimento 205/2021 do CFOAB

## 🛠️ Comandos

```bash
# Instalar dependências
npm install

# Rodar servidor local
npm run dev

# Gerar build estático para produção (pasta /out)
npm run build
```
